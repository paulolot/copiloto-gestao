# Copiloto Gestão

Agentes de IA que executam o ciclo de trabalho de um coordenador de desenvolvimento: boards do Azure DevOps, Google Workspace, reuniões no Meet, 1:1 e PDI, reunião com o CTO e uma memória própria em markdown.

O cérebro é o Grok Bot; este repositório contém a **ponte MCP** que dá a ele acesso seguro ao Azure DevOps, ao vault e ao Discord, a **extensão do Meet**, os **textos das skills e rotinas** e o **modelo do vault**.

- Plano: [`docs/plano.md`](docs/plano.md)
- Requisitos: [`docs/requisitos.md`](docs/requisitos.md)
- Fase atual: [`docs/backlog-fase-0.md`](docs/backlog-fase-0.md)
- O que depende do Paulo: [`docs/checklist-paulo.md`](docs/checklist-paulo.md)
- Contexto para sessões de desenvolvimento: [`CLAUDE.md`](CLAUDE.md)

> Este repositório não guarda segredos nem dados do vault. O vault vive num repositório privado separado.
